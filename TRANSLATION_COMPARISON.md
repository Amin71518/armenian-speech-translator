является процентом правильных переводов. NLLB требует больше памяти и времени,

NLLB с двумя лучами: chrF++ **56,83**, среднее время 3,805 / 6,585 с,

дополнительного луча по нему нельзя. Качество не улучшилось, ошибки сохранились,
поэтому выбран greedy.

## Примеры и ограничения качества

`005`, формат фотографии 35 мм: Marian выдаёт “35 meters per second”, NLLB —
“the most common format of still photography in the world is 35mm”.
`015`, растения и фотосинтез: Marian — “The plants receive their food through the
bacteria”; NLLB — “The plants get their food through photosynthesis. They also
provide shade.”; M2M100 — “The bears get their food through the photovoltaic
they are also safe”. В `002` M2M100 превращает лёд, снег и движение в “spine” и
“liver”. Эти подмены смысла подтверждают преимущество NLLB среди проверенных настроек.

На нормализованных эталонах NLLB всё ещё ошибается: `001` сливает train и car в
“train car”; `003` заменяет riders на horses; `004` теряет часть про аудиторию;
`008` заменяет Luna на “swimming pool”; `013` переводит prides как predators;
`014` теряет субъект USA Gymnastics. Это не переводчик с гарантированной точностью.

В полной цепочке результаты отличаются, поскольку ASR сохраняет регистр и пунктуацию.
`001` перечисляет train и car отдельно, `008` передаёт Lona из ASR, `014` сохраняет
U.S. Gymnastics. Но `012` ошибка ASR дополнительно меняет людей на photographers,
а `003` и `004` остаются проблемными. Этими результатами не подменяется отдельная
оценка переводчика на правильных текстах.

## Методика

Все модели получают правильные нормализованные армянские расшифровки из прежнего
manifest FLEURS. Распознанный ASR-текст не используется при выборе переводчика.
Английские эталоны сопоставлены по ID предложений. Состав и порядок 15 примеров
не меняются. Это читаемые тексты, а не проверка реального разговора.

CPU float32, четыре потока PyTorch, batch size 1, num_beams=1, do_sample=False,
max_new_tokens=256. Модель загружается один раз на процесс; два прохода по текстам
выполняются последовательно. Загрузка и инференс измеряются отдельно. Первый
проход включает первый инференс, второй повторно использует загруженную модель.
Время перевода исключает печать, метрики и ASR. Память — sampled peak RSS
процесса каждые 50 мс, включая загрузку и оба прохода, не точный аппаратный пик.
Отдельно проверяется NLLB с num_beams=2; его результат не смешивается с greedy.

Направления задаются явно: NLLB `hye_Armn` → `eng_Latn`, M2M100 `hy` → `en`.
Для многоязычных моделей язык назначения задаётся через forced_bos_token_id.
Вход не обрезается молча: превышение лимита токенов является ошибкой.
Для NLLB используется лимит 512 токенов согласно описанию обучения модели.

Вспомогательная метрика — corpus chrF++ SacreBLEU 2.6.0, word_order=2,
шкала 0–100, больше лучше. Сохраняется полная сигнатура метрики. Она измеряет
сходство с единственным английским эталоном и не заменяет проверку смысла.
Имена, числа, отрицания, пропуски и добавления оцениваются по английским примерам.
Это предварительное сравнение, не экспертная оценка носителя армянского языка.

Набор FLEURS связан с FLORES, используемым при оценке NLLB. Эти 15 предложений
нельзя считать доказательством качества на независимой разговорной выборке.
Окончательная проверка требует новых примеров вне текущего набора.

## Особенности подготовки на Windows

Первое параллельное скачивание завершилось WinError 1314 при создании ссылок
в кэше Hugging Face, хотя веса уже были загружены. В helper установлен
max_workers=1: последовательная подготовка успешно использовала сохранённые файлы.
Библиотека сама использует обычные файлы, когда symlink недоступен; её код не менялся,
права администратора и изменение настроек Windows не потребовались.

Transformers 4.57.6 при загрузке NLLB-токенизатора по repo ID вызывал model_info
в проверке Mistral-токенизаторов даже с local_files_only=True. Переводчик теперь
разрешает уже подготовленный pinned snapshot через snapshot_download с
local_files_only=True и передаёт локальный путь в AutoTokenizer/AutoModel.
Это устраняет запрос метаданных; реальный NLLB-прогон подтвердил работу в
окружении без сетевого доступа. Никакой замены весов или модели при ошибках нет.

Во время ранних экспериментов обнаружена работа от батареи со схемой «Сбалансированная».
Время одинаковых переводов заметно менялось между запусками. Поэтому результаты
нужно читать с учётом условий питания и фоновой нагрузки, а не как гарантированную
верхнюю границу задержки. Финальные greedy-прогоны и полная цепочка выполнены
уже при подключённом питании. Для итогового теста на интервью нужен повтор в условиях,
в которых будет работать приложение. Настройки питания программно не менялись.

## Воспроизведение

```powershell
poetry run python scripts/download_translation.py --model nllb
poetry run python scripts/check_translation.py --manifest data/local/fleurs/manifest.jsonl --model Helsinki-NLP/opus-mt-hy-en --offline --report reports/marian_translation.json
poetry run python scripts/check_translation.py --manifest data/local/fleurs/manifest.jsonl --model facebook/nllb-200-distilled-600M --offline --report reports/nllb_translation.json
poetry run python scripts/download_translation.py --model m2m100
poetry run python scripts/check_translation.py --manifest data/local/fleurs/manifest.jsonl --model facebook/m2m100_418M --offline --report reports/m2m100_translation.json
```

Запускать последовательно. Скачивание весов выполняется отдельно; его длительность
не включается в время перевода. Для фиксации скачиваемой ревизии поддерживается
`scripts/download_translation.py --revision COMMIT`. Фактическая ревизия модели
сохраняется в JSON-отчёте. Отчёты остаются вне Git; общие результаты и выбранные
примеры фиксируются здесь. Обычный WAV CLI не сохраняет распознанные тексты и переводы.

Ревизии: NLLB `f8d333a098d19b4fd9a8b18f94170487ad3f821d`, M2M100
`55c2e61bbf05dfb8d7abccdc3fae6fc8512fd636`, Marian
`79b0a5051bdb77155f96bb5f091c054ff575b04b`. Runtime двух кандидатов читает pinned
snapshot. Manifest SHA-256:
`8d7e72f87970345fc5dd454f3f0368d63fcfae325eaf7a7185cf940dd582854c`.

Сигнатура: `nrefs:1|case:mixed|eff:yes|nc:6|nw:2|space:no|version:2.6.0`.
Python 3.13.5, PyTorch 2.15.0+cpu, Transformers 4.57.6, tokenizers 0.22.2.
Основные JSON в reports/: marian_translation_final, nllb_translation_final,
m2m100_translation, vana_nllb_pipeline. Диагностический nllb_beam2_translation
отделён от финального сравнения.

**22 теста прошли**, Ruff — без замечаний. Покрыты языковые коды, английский BOS,
локальный snapshot, лимиты входа, пустой текст, отказ на неизвестной модели,
новый default CLI и прежний контракт pipeline. Это не заменяет независимую оценку качества.
